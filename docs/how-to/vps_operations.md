# Operaciones Remotas Quirúrgicas en VPS (Diátaxis / How-To)

> **Propósito:** Guía práctica para controlar y sincronizar la VPS mediante sockets SSH multiplexados a < 8 ms.

---

## 1. Diagnóstico Ultradenso de Salud (< 50 Tokens)
```bash
agy-opt vps-health
```

---

## 2. Ejecución Remota con Poda Automática de Logs (80% Ahorro)
```bash
agy-opt vps-run "docker ps; uptime; free -h"
```

---

## 3. Lectura Quirúrgica Remota de Líneas
```bash
agy-opt vps-read /root/.bashrc 1 30
```

---

## 4. Parche Quirúrgico in-place (Sin Reescribir Archivos)
```bash
agy-opt vps-patch /root/app.py --target "v1.0" --replacement "v2.0"
```

---

## 5. Sincronización de Símbolos AST a tu RAM Local
```bash
agy-opt vps-index /root/proyectos_software
```
